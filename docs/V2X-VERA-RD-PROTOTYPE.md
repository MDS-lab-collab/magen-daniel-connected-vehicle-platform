# MDS V2X VERA — R&D Prototype

**Engineering Evaluation & Development Platform**

MDS V2X VERA is a research-and-development prototype from Magen Daniel Systems LLP for teams, developers, laboratories, and companies that want to evaluate connected-vehicle and wireless communication concepts without starting hardware development from zero.

> **Prototype notice:** This is an engineering evaluation unit, not a finished or certified automotive production product.

## Purpose

The platform is intended to provide an existing hardware base for:

- LoRa / sub-GHz wireless communication evaluation
- Connected-vehicle and V2X research
- IoT and telemetry development
- GNSS/location-aware applications
- Cellular-connected prototypes
- Firmware and system integration experiments
- Proof-of-concept and university/laboratory R&D

The main value of the prototype is that a technical team can begin from an existing integrated platform and continue its own engineering work rather than starting a complete board design from zero.

## Hardware Platform

The prototype platform includes the following major hardware blocks:

- Nordic nRF54L15 main MCU
- SX1262 LoRa radio
- EG800Z cellular/LTE module
- GNSS positioning module
- ESP32-C3 Wi-Fi module
- SIM interface
- USB-C interface
- External RF antenna connections
- Integrated power regulation and protection circuitry

Exact configuration may vary between prototype revisions.

## Development & Testing Status

The platform has been used for internal engineering and wireless communication testing.

LoRa operation has been evaluated during prototype field testing at 433 MHz and 868 MHz. Results varied according to frequency, antenna, RF configuration, route obstruction, firmware settings, and test environment.

No fixed communication range is guaranteed. Future or customized versions may use different RF hardware, antennas, power levels, matching networks, or regional configurations.
